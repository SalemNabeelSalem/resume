> A modern, automated, and code-driven approach to maintaining and generating a clean professional CV using **RenderCV**, **YAML**, and **Python**.

---

## 💡 Overview

Managing a resume in traditional document editors often leads to formatting headaches, inconsistent alignment, and difficult version control. 

This repository treats my CV as code. By leveraging **YAML** for structured data storage and **RenderCV** for typesetting, updating my professional background is as simple as committing a text change ensuring a clean, reproducible, and beautiful PDF layout every time.

---

## ✨ Key Features

- 🎯 **Data-Driven**: Plain-text YAML source file keeps content completely separated from design.
- ⚡ **Automated Generation**: Produces polished, high-quality LaTeX-rendered PDFs programmatically.
- 🛠️ **Version Controlled**: Easily track historical changes to career milestones, skills, and projects over time.
- 📱 **Multi-Format Ready**: Easily exports to both PDF and Markdown/HTML formats.
